Fluxo de compra de livro (registro + carrinho):

O usuario acessa o site Demo Web Shop.
O usuario clica no link Register para acessar a pagina de registro.
O sistema exibe o formulario de registro.
O usuario preenche o campo de email com um email valido.
O usuario preenche o campo de senha com uma senha segura.
O usuario confirma a senha digitando-a novamente.
O usuario preenche o campo First Name com seu primeiro nome.
O usuario preenche o campo Last Name com seu sobrenome.
O usuario clica no botao Register para completar o registro.
O sistema valida os dados e registra o usuario automaticamente.
O usuario fica logado apos o registro.
O usuario e redirecionado para a pagina inicial.
O usuario clica no menu ou link Books para acessar a lista de livros.
O sistema exibe a pagina de catalogo de livros disponiveis.
O usuario localiza e clica no livro Health Book para abrir sua pagina de detalhes.
O sistema exibe a pagina do produto com descricao, preco e opcoes de compra.
O usuario clica no botao Add to cart para adicionar o livro ao carrinho.
O sistema confirma que o produto foi adicionado ao carrinho (notificacao de sucesso).
O usuario navega para o carrinho de compras para verificar o item adicionado.
O sistema exibe o carrinho contendo o livro Health Book com quantidade e preco.
O usuario verifica que o livro foi adicionado com sucesso ao carrinho.
